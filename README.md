# MyFinance

Personal finance management PWA starter.

## Files
- `index.html` - app structure
- `style.css` - responsive purple theme
- `app.js` - UI behavior and local browser storage
- `config.js` - non-secret app configuration
- `manifest.json` - PWA metadata
- `sw.js` - offline app shell cache

## Current limitations
This starter stores transactions, budgets, goals and bills in the current browser using `localStorage`. It does not sync across devices and is not connected to Google Sheets yet.

Do not put API tokens, passwords, spreadsheet secrets, or private credentials in this public repository.
